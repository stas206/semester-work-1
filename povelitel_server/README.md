# Повелитель Токио — вики-сайт на собственном HTTP-сервере

Небольшой вики-портал по настольной игре «Повелитель Токио», написанный на C# (.NET 10) без использования ASP.NET. HTTP-сервер на базе `HttpListener`, маршрутизация, шаблонизатор, ORM и авторизация по сессиям реализованы вручную, данные хранятся в PostgreSQL.

## Что понадобится

* **Вариант 1 (проще):** Docker и Docker Compose — поднимут и базу, и сам сервер одной командой.
* **Вариант 2 (локально):** .NET 10 SDK и PostgreSQL 16.

## Быстрый старт через Docker

```bash
docker-compose up --build
```

При первом запуске PostgreSQL сам создаст таблицы и заполнит их начальными данными из папки `sql/`. После старта сайт будет доступен по адресу: [http://localhost:8888](http://localhost:8888).

## Локальный запуск (без Docker)

### 1. Настройка базы данных

В папке `sql/` лежат два скрипта:
* `01_schema.sql` — создание таблиц (`cards`, `items`, `rules`, `strategies`, `users`) и индексов;
* `02_seed.sql` — стартовое наполнение (карты, компоненты игры, правила, стратегии и учётная запись администратора).

Создайте пользователя и базу данных, затем накатите скрипты:

```bash
psql -U postgres -c "CREATE USER pt_user WITH PASSWORD 'pt_pass';"
psql -U postgres -c "CREATE DATABASE povelitel_tokio OWNER pt_user;"

psql -U pt_user -d povelitel_tokio -f sql/01_schema.sql
psql -U pt_user -d povelitel_tokio -f sql/02_seed.sql
```

Строка подключения лежит в `MiniHttpServer/settings.json` (или `appsettings.json`):

```text
Host=localhost;Port=5432;Database=povelitel_tokio;Username=pt_user;Password=pt_pass;Include Error Detail=true
```

При необходимости параметры можно переопределить через переменные окружения `PT_CONNECTION_STRING`, `PT_SERVER_HOST` и `PT_SERVER_PORT`.

### 2. Запуск сервера

```bash
dotnet run --project MiniHttpServer/MiniHttpServer.csproj
```

Сервер запустится на [http://127.0.0.1:8888](http://127.0.0.1:8888). Для корректной остановки достаточно ввести `stop` в консоли.

## Админ-панель и возможности

Обычным посетителям регистрация не нужна — разделы с картами, предметами, правилами и стратегиями открыты для просмотра, есть фильтрация по тегам и живой поиск по картам без перезагрузки страницы.

Для управления контентом предусмотрен вход для администратора (кнопка в шапке сайта):
* **Логин:** `admin`
* **Пароль:** `admin123`

После авторизации сверху появляется панель администратора со ссылкой на `/admin/index`, где доступен полный CRUD:
* **Карты и предметы** — добавление, редактирование и удаление (изображения загружаются прямо из формы, автоматически сжимаются на клиенте до 600 px по большей стороне и сохраняются в `static/assets/images/uploads/`);
* **Правила и стратегии** — редактируются через визуальный WYSIWYG-редактор **Quill**;
* **Удаление записей** — происходит асинхронно через `fetch`, без перезагрузки страницы.


## Структура решения

* `MiniHttpServer/` — веб-приложение: контроллеры, валидация, HTML-шаблоны (`Templates/`), статика (`static/assets/`) и конфигурация.
* `MiniHttpServer.Framework/` — ядро сервера на `HttpListener`, цепочка обработчиков, роутинг, DI-фабрика контроллеров и сессии.
* `MiniHttpServer.ORM/` — мини-ORM для PostgreSQL (генерация SQL через рефлексию, маппинг сущностей и репозитории).
* `MiniHttpServer.HtmlTemplating/` — собственный шаблонизатор с поддержкой `${...}`, `$if` / `$else`, `$foreach` и `$raw(...)`.
* `sql/` — SQL-скрипты схемы и начальных данных.
